# API para projeto "frota-pro"

Esta API  permite o gerenciamento de frota de um Batalhão de Policia Militar. A API é projetada para ser utilizada app "Frota-Pro" para autenticação de usuarios, gerenciamento da frota, cadastro de controle de pilotos.

## Introdução

A API é  aplicação desenvolvida para permitir o cadastro, atualização e consulta de informações sobre veículos de uma frota. Com ela, é possível registrar novos veículos, visualizar informações detalhadas e atualizar dados como quilometragem e status.

## Pré-requisitos

Para rodar esta API, você precisará de:

- Node.js v14 ou superior
- MongoDB (para armazenamento de dados)
- Postman ou qualquer outra ferramenta para testes de API (opcional)
